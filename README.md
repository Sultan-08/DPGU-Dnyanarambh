# 🎓 Dnyanarambh – Student Induction Management Platform

> A production-ready web platform developed for DPGU SMR 15-day student induction program.

> **Note:** This repository is a project showcase and case study. The application source code is intentionally kept private because it was developed for institutional use.

## 📖 Problem Statement
Every academic year, DPGU welcomes hundreds of first-year students through its 15-day induction program called **Dnyanarambh**.

Managing student registrations, login credentials, event schedules, and communication manually can become time-consuming and inefficient.

The goal of this project was to digitalize the complete induction workflow through a centralized web application.

## 🌍 Real-World Usage
This application was successfully deployed and used during DPGU SMR's actual student induction program.

## ✨ Features
🏢 Year-wise Administration.
👨‍🎓 Student Registration.
🔐 Secure Authentication.
📅 Interactive 15-Day Timeline.
📍 Venue & Schedule Management.
🔄 Multi-Year Reusability.
☁ Production Cloud Deployment.
📱 Fully Responsive.

## 🛠 Tech Stack
- React + Vite
- Node.js + Express
- MongoDB Atlas
- Git
- Docker
- AWS EC2
- Elastic IP
- AWS Secrets Manager
- IAM
- Docker Hub

## 🚀 Deployment Journey
Local Development → Docker → Docker Hub → AWS EC2 → Secrets Manager → MongoDB Atlas → Production.
