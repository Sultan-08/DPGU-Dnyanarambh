# 🎓 Dnyanarambh – Student Induction Management Platform

> A production-ready web platform developed for DPG University's 15-day student induction program.

> **Note:** This repository is a project showcase and case study. The application source code is intentionally kept private because it was developed for institutional use.

## 📖 Problem Statement
Every academic year, DPG University welcomes hundreds of first-year students through its 15-day induction program called **Dnyanarambh**.

Managing student registrations, login credentials, event schedules, and communication manually can become time-consuming and inefficient.

The goal of this project was to digitize the complete induction workflow through a centralized web application.

## 🌍 Real-World Usage
This application was successfully deployed and used during DPG University's actual student induction program.

## ✨ Features
- Year-wise Administration
- Student Registration & Login
- Automated Onboarding
- Interactive 15-Day Timeline
- Multi-Year Reusability
- JWT Authentication
- Cloud Deployment

## 🛠 Tech Stack

## 🏗 Architecture
Users → React → Express API → JWT → MongoDB Atlas

Docker → Docker Hub → AWS EC2 → Elastic IP

## 🚀 Deployment Journey
Local Development → Docker → Docker Hub → AWS EC2 → Secrets Manager → MongoDB Atlas → Production
